This is the first PyCarinthia meetup. The goal is simple: meet the people using Python in Carinthia and shape the group together.

Expect a short opening talk, lightning introductions, and a practical discussion about topics, venues, formats, and what people want from a local Python user group.

Beginners, students, hobbyists, professionals, data people, web developers, AI builders, automation fans, and the merely curious are all welcome.
