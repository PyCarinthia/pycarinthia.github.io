Description: About PyCarinthia, the Python user group for Carinthia.

PyCarinthia is an open community for people in Carinthia who use Python, want to learn it, or work around it through data, web development, automation, scientific computing, AI, teaching, and open source.

The goal is to make local Python work visible and approachable. We meet to share talks, demos, workshops, project stories, and practical lessons from real work.

There is no membership and no required level. If you have never written Python before, you are welcome. If you run Python in production every day, you are welcome too.

## What a meetup looks like

A typical evening has one short talk, a few lightning talks or demos, time for questions, and conversation afterwards. Some sessions can be hands-on workshops or open coding evenings.

## Language

Talks, event descriptions, and public meetup content are in English by default so international students, visitors, and non-German speakers can participate.

German is welcome in informal conversation, and the group can help bridge questions when useful.

## Code of conduct

PyCarinthia follows the spirit of the [Python Software Foundation Code of Conduct](https://www.python.org/psf/conduct/). Be open, considerate, and respectful. Harassment is not tolerated.
