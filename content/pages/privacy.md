## Website purpose

PyCarinthia is a non-commercial community website for the Python user group in Carinthia. The website publishes event information, community resources, and information about software development, information technology, open source, and Python.

## Static website

This website is built with [Pelican](https://getpelican.com/) and published as static HTML. The current site does not embed comments, advertising, or analytics scripts.

PyCarinthia does not intentionally set tracking cookies on this website.

## Hosting and server logs

The site is intended to be published with [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages). According to GitHub's documentation, GitHub Pages logs visitor IP addresses for security purposes when a GitHub Pages site is visited.

More information is available in the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Map display

The homepage can display a venue map using [basemap.at](https://basemap.at/) map tiles. When the map is loaded, the tile service provider may receive technical request data such as your IP address, browser information, timestamp, and requested map tile URLs.

The route-planning button opens Google Maps only when you click it. Google is then responsible for the data processing on its own service.

## Contact and proposal forms

PyCarinthia may use linked Google Forms for general contact and talk proposals. If you use those forms, the data you submit, such as your name, email address, message, proposal details, and related technical metadata, is processed so the message can be answered and the community can coordinate talks, venues, events, and organizing work.

Google is responsible for its own service-side data processing. More information is available in the [Google Privacy Policy](https://policies.google.com/privacy).

## Event registration

PyCarinthia may use linked Google Forms or [Lu.ma](https://lu.ma/) for free meetup RSVPs, guest lists, reminders, and event updates. If you register for an event through one of those services, the respective provider is responsible for its own service-side data processing.

## External services and links

This website links to external services such as Google Forms, Lu.ma, GitHub, Python community pages, and regional event websites. If you follow those links, the respective provider is responsible for its own data processing.

## Remote content feeds

The site can be extended with remote event or resource feeds at build time. This does not create client-side tracking by itself; it only changes the static content that is published.
